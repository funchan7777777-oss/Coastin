# Coastin

Coastin is a Flutter iOS project for calm shoreline planning: tide windows,
cove pauses, route comfort, and small harbor notes.

The codebase keeps app bootstrap, theme tokens, domain entities, seed content,
and board UI separated under `lib` so later feature work has room to grow
without falling back into a generic starter shape.
